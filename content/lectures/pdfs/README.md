# Lecturer Slide Handouts Notice

Official lecturer slide handouts (*.pdf) are omitted from this public repository for academic copyright compliance with the University of Moratuwa.

### Local Study Option:
If you are an enrolled student possessing official course slide PDFs, place the matching PDF files in this directory:
- `Lec1.pdf` (Chapter 1)
- `Lec2.pdf` (Chapter 2)
- `Lec3.pdf` (Chapter 3)
- `PCA-R-2013.pdf` (Chapter 4)
- `Lec5.pdf` (Chapter 5)
- `Lec5Extra.pdf` (Chapter 6)
- `Lec6.pdf` (Chapter 7)
- `Lec7.pdf` (Chapter 8)
- `Lec8.pdf` (Chapter 9)
- `Lec9.pdf` (Chapter 10)
- `Multivariate-Linear-Models.pdf` (Chapter 11)

Then run `npm run build` to assemble a local build with embedded slide viewers.
